 # 🎯 Jogo da Forca

Jogo da forca para jogar no terminal, feito em ** Python 2 ** como trabalho da escola, no primeiro ano do ensino médio (2015/2016).

> Este é um projeto antigo, publicado como parte da minha linha do tempo. O código está como foi entregue na época.

## Como jogar

1. Abra o jogo e escolha ** 1 ** no menu para começar.
2. Digite ** uma letra por vez ** , em letra minuscula.
3. Letras maiúsculas, números, caracteres especiais ou duas letras de uma vez contam como erro.
4. Com ** 6 erros ** , o boneco e enforcado e o jogo acaba. Descubra a palavra antes disso.

O menu também tem as opções de ** Desenvolvedores ** , ** Instruções ** e ** Sair **.

## Como rodar

O jogo foi feito em ** Python 2 ** e ** não funciona no Python 3 **. Com o Python 2.7 instalado, abra o terminal na pasta do projeto e digite:

```
python forca.py
```

As palavras do jogo ficam no arquivo dados.txt, ** uma palavra por linha ** , em letras minúsculas e sem acento. Você pode adicionar as suas.

## Limitações conhecidas

- Funciona somente em Python 2.
- A segunda partida na mesma execução não reinicia direito. Basta fechar e abrir o jogo de novo.
- Palavras com acento não funcionam.
